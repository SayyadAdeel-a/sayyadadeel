# Relab — Clone Research Index

Source: <https://relab-template.webflow.io/> → route `/`
Site key: `relab-0c02b053` · Page key: `root-8a5edab2`

> **This folder documents the homepage only.** It was built first, by hand, and
> is frozen. The other 24 routes are generated by `scripts/convert-page.mjs` from
> captured source material; see the [site-level index](../README.md),
> [PIPELINE.md](../PIPELINE.md) and [IX3-ENGINE.md](../IX3-ENGINE.md).
> The homepage keeps its own runtime, `src/components/sites/adeel-site/shared/InteractionsRuntime.tsx`,
> which the generated pages do not use.

This folder is the auditable record of how the clone was built. Every file here
was produced by a script in `scripts/`, so the extraction can be re-run and
re-checked at any time.

## Captured source material

| File | What it is |
| --- | --- |
| `live-page.html` | The complete served HTML of the page (148 KB, minified Webflow output). Generated by the Webflow runtime, so it already contains the inline styles the IX engine writes. |
| `live-webflow.css` | The site's stylesheet, byte-for-byte from the CDN. |
| `lenis.css` | `lenis@1.1.14/dist/lenis.css`, loaded by the page. |
| `webflow-js/` | Every JS file the page loads (Webflow runtime chunks, jQuery, GSAP 3.15 core/ScrollTrigger/SplitText/Observer, Lenis 1.1.14, WebFont loader). |
| `scripts-inline/` | The page's own inline scripts, including the hand-written hero-intro tab switcher. |
| `webflow-ix2.json` | Webflow IX (ix3) interactions + timelines, decoded from `webflow.a3e096e3.*.js`. 28 interactions, 30 timelines. |
| `IX2-READABLE.md` | Human-readable dump of the payload above — the animation specification. |
| `webflow-ix.json` | The legacy (ix2) `data.events` payload (26 events), kept for completeness. |
| `asset-map.json` | CDN URL → local path for every downloaded asset. |
| `image-variants.json` | Every responsive `srcset` candidate referenced by the page. |
| `sections/` | Per-section HTML snapshots. |
| `style-probe-selectors.txt` | The selector list used by the computed-style parity harness. |
| `style-report-{1440,768,390}.txt` | Output of that harness at each breakpoint. |

## Reproduction order

```bash
node scripts/download-webflow-js.mjs    # capture the page's runtime
node scripts/extract-inline.mjs         # capture inline scripts
node scripts/extract-ix2.mjs            # decode the IX interaction payload
node scripts/read-ix2.mjs > IX2-READABLE.md
node scripts/download-variants.mjs     # responsive image candidates
node scripts/localize-css.mjs           # rewrite app/webflow.css to local URLs
node scripts/convert-to-jsx.mjs         # generate the section components
node scripts/verify-assets.mjs         # confirm every local reference exists
node scripts/generate-specs.mjs         # regenerate the component specs
npm run build
```

## Visual QA

```bash
node scripts/rebuild.mjs                                   # build + serve :3100
node scripts/compare.mjs --width=1440 --height=900 --full  # screenshots
node scripts/diff-images.mjs <ref.png> <clone.png>         # pixel diff
node scripts/compare-dom-shape.mjs 1440 900                # DOM tree parity
node scripts/compare-dom.mjs --width=1440 --static        # bounding-box parity
node scripts/compare-styles.mjs --width=1440              # computed styles
node scripts/compare-behavior.mjs --width=1440            # interaction parity
node scripts/compare-images.mjs 1440 900                  # <img> metadata
```

Results are recorded in `QA_REPORT.md`.
